# Протокол КП ↔ ESP8266 (v1)

UART 19200 8N1. Текстові рядки, закінчуються `\r\n` (приймається також лише `\r` або `\n`).

```
$<CMD>[,<поле>...]*HH\r\n
```

* `HH` — XOR усіх символів між `$` і `*`, дві hex-цифри (як у NMEA). Приклад: `$HB*0A`.
* Рядки, що починаються з `#`, — налагоджувальні логи КП. ESP їх ігнорує.
* Максимальна довжина рядка між `$` і кінцем — 40 символів.
* `PROTO_ALLOW_NO_CHECKSUM = 1` (proto.h): КП приймає рядки **без** `*HH`, щоб команди можна було набирати руками в терміналі. Після підключення ESP поставте `0`.
* Регістр команд не важливий (`$gs` = `$GS`).

## КП → ESP

| Рядок | Коли |
|---|---|
| `$HELLO,LEAKDET,<версія>` | при старті та на `$VER` |
| `$ST,<state>,<pos>,<leak>,<fault>,<alarm>,<relays>,<link>` | при будь-якій зміні та не рідше ніж раз на 2 с |
| `$OK,<cmd>` | команду виконано |
| `$ER,<cmd>,<причина>` | команду відхилено |

Поля `$ST`:

| Поле | Значення |
|---|---|
| state | `INIT` `OPENING` `OPEN` `CLOSING` `CLOSED` (закрито вручну) `ALARM` (протічка, чекає RESET) `FAULT` |
| pos | положення крана за кінцевиками: `OPEN` `CLOSED` `MID` (між ними) `FAULT` (обидва активні) |
| leak | hex-маска мокрих датчиків, біт 0 = датчик «1» |
| fault | `NONE` `OTMO` (таймаут відкриття) `CTMO` (таймаут закриття) `SW` (кінцевики) |
| alarm | `1` — аварія зафіксована (latch, зберігається в EEPROM) |
| relays | hex-маска увімкнених реле, біт N = реле N (0 — закриття крана, 1 — відкриття) |
| link | `1` — КП бачить ESP (приходять валідні кадри) |

Причини `$ER`: `CS` (контрольна сума), `LEN` (задовгий рядок), `FMT` (недопустимий символ), `ARG` (аргументи), `DENIED` (заборонено), `WET` (датчик ще мокрий), `UNK` (невідома команда).

## ESP → КП

| Команда | Дія | Відповідь |
|---|---|---|
| `$HB` | heartbeat | немає |
| `$GS` | надіслати статус зараз | `$ST,...` |
| `$VER` | версія | `$HELLO,...` |
| `$OPEN` | як кнопка RESET: скинути аварію / несправність, відкрити кран | `$OK,OPEN` або `$ER,OPEN,WET` / `DENIED` |
| `$CLOSE` | як кнопка CLOSE: закрити кран | `$OK,CLOSE` |
| `$RL,<n>,<0\|1>[,<lease_s>]` | увімкнути/вимкнути реле n = 2..6 | `$OK,RL` / `$ER,RL,...` |
| `$?` | список команд (рядками `#`) | — |

`$OK` на `$OPEN`/`$CLOSE` означає «команду прийнято», фактичний результат видно в наступному `$ST`.

## Правила безпеки

1. **Реле 0 і 1 (мотор крана) ESP не керує** — `$ER,RL,DENIED`.
2. **Lease.** `$RL,n,1,60` — реле увімкнеться на 60 с. Якщо ESP не повторить команду, КП сам вимкне реле. Рекомендація для ESP: повторювати кожні lease/3 (для котла: `lease=60`, повтор кожні 20 с). `lease` 0 або відсутній — без обмеження часу. Максимум 3600 с, точність ±1 с.
3. **Втрата зв'язку.** Якщо від ESP 10 с немає жодного валідного кадру, КП вимикає **всі** реле 2..6 і показує `link=0`. ESP має слати `$HB` хоча б раз на 3 с.
4. Захист від протічки не залежить від ESP: кран закривається і без зв'язку.
5. `PROTO_ALLOW_REMOTE_OPEN = 0` (proto.h) забороняє скидати аварію через `$OPEN` — тільки фізичною кнопкою.

## Налагодження з ПК

USB-UART адаптер до TX/RX/GND КП (замість ESP), потім:

```
pip install pyserial
python tools/esp_sim.py COM5
```

Скрипт сам шле `$HB`, рахує контрольні суми, розшифровує `$ST`. Команди: `gs`, `open`, `close`, `rl 2 1 60`, `keep 2 30` (тримати реле увімкненим з автоматичним оновленням lease), `hb off` (перевірити реакцію на втрату зв'язку), `bad HB` (кадр з неправильною сумою), `?` — довідка.

Або будь-який термінал (PuTTY, Termite): набирайте `$gs`, `$rl,2,1,30`, `$?` + Enter.
